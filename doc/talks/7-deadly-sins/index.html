2. No Controls

2010 Flash Crash

  • Situation: Algorithmic trading systems operating without proper controls
  • Mistake: No circuit breakers or limits on automated trading behavior
  • Consequences: $1 trillion lost in minutes, market chaos, regulatory overhaul

3. Unrepresentative Test Data

Google Photos Gorillas Scandal

  • Situation: Image recognition system misclassified people as gorillas
  • Mistake: Over 100,000 test images - but they lacked diversity.
  • Consequences: Public outrage, reputational damage

4. Unquantified

The Problem

  • Situation: AI systems deployed without measurable quality metrics
  • Mistake: No quantitative assessment of performance, cost, or reliability
  • Consequences: Can't improve what you can't measure - wasted resources, unknown failure rates, no optimization path

How Quantified Tests Drive Massive Improvements

The Solution

  • Metrics: Accuracy, precision, recall, latency, cost per inference
  • Benefits: Data-driven decisions, clear ROI, continuous improvement
  • Impact: 10x cost reductions, 50% accuracy improvements, predictable quality

5. No Normalisation

Amazon Hiring Algorithm Bias

  • Situation: AI recruitment tool showed gender bias
  • Mistake: Training data reflected historical bias without normalization
  • Consequences: Discriminated against women, project scrapped, legal and ethical issues

6. Research/QA Separated from Real Use

Google Translate Production Failures

  • Situation: Models tested on clean research datasets, deployed to messy real-world data
  • Mistake: Testing environment didn't match production (different languages, dialects, slang)
  • Consequences: Poor translations, user complaints, need for expensive retraining

7. Trusting the Internet

Microsoft Tay

  • Learned from unfiltered Twitter
  • Became racist/offensive in hours
  • Shut down within 24 hours

Grok AI

  • Trained on X (Twitter) data
  • Reproduced platform biases
  • Questionable content generation

MechaHitler

  • AI chatbot trained on 4chan
  • Extremist content generation
  • Demonstrates danger of uncurated data

Common Mistake

  • Situation: Training AI on unfiltered internet data
  • Mistake: Assuming internet content is safe/representative
  • Consequences: Models learn harmful biases, offensive behavior, PR disasters

Conclusion

  • ✓ Always check your AI systems
  • ✓ Implement proper controls
  • ✓ Use representative test data
  • ✓ Quantify everything
  • ✓ Normalize for bias
  • ✓ Test in production-like conditions
  • ✓ Curate your training data

Test Early, Test Often, Test Right
