Is Your AI Agent Doing What You Want? Practical Observability for Agentic AI

## 9.Describe your proposed session, including key benefits for the audience (max 200 words)
Enter your answer

As AI systems move from generating answers to taking actions, traditional software observability is no longer enough. An agent can have zero API errors, low latency and a successful execution trace - while completely failing the user’s objective.

Fortunately ways to tackle this have emerged. With the right approach, observability and QA become tools for faster as well as safer development.

This session offers a three-layer framework:

- Is the agent running? (system behaviour)
- Is it doing the right thing? (task-level outputs)
- Is it delivering value? (real-world impact)

We will cover how to instrument agent systems, measure task success alongside metrics like cost and latency, and catch quality regressions.

The session draws on experience building and evaluating LLM-powered assistants, including automated evaluation, evaluator models, labelled examples and feedback loops. Attendees will leave able to tell whether their agent is doing what they want.
